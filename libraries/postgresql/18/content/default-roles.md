## O.2. Default Roles Renamed to Predefined Roles

PostgreSQL 13 and below used the term “Default Roles”. However, as these roles are not able to actually be changed and are installed as part of the system at initialization time, the more appropriate term to use is “Predefined Roles”. See [Section 21.5](predefined-roles.html "21.5. Predefined Roles") for current documentation regarding Predefined Roles, and [the release notes for PostgreSQL 14](release-prior.html "E.7. Prior Releases") for details on this change.
