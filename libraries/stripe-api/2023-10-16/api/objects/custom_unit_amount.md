# Stripe API 2023-10-16 — `custom_unit_amount` object

| Field | Type | Required | Description |
|---|---|---|---|
| `maximum` | integer |  | The maximum unit amount the customer can specify for this item. |
| `minimum` | integer |  | The minimum unit amount the customer can specify for this item. Must be at least the minimum charge amount. |
| `preset` | integer |  | The starting unit amount which can be updated by the customer. |
