# Stripe API 2023-10-16 — `period` object

| Field | Type | Required | Description |
|---|---|---|---|
| `end` | timestamp (Unix seconds) |  | The end date of this usage period. All usage up to and including this point in time is included. |
| `start` | timestamp (Unix seconds) |  | The start date of this usage period. All usage after this point in time is included. |
