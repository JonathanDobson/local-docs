# Stripe API 2023-10-16 — `radar_radar_options` object

Options to configure Radar. See [Radar Session](https://stripe.com/docs/radar/radar-session) for more information.

| Field | Type | Required | Description |
|---|---|---|---|
| `session` | string |  | A [Radar Session](https://stripe.com/docs/radar/radar-session) is a snapshot of the browser metadata and device details that help Radar make more accurate predictions on your payments. |
