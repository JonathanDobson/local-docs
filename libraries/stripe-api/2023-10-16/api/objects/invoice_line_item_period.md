# Stripe API 2023-10-16 — `invoice_line_item_period` object

| Field | Type | Required | Description |
|---|---|---|---|
| `end` | timestamp (Unix seconds) | yes | The end of the period, which must be greater than or equal to the start. This value is inclusive. |
| `start` | timestamp (Unix seconds) | yes | The start of the period. This value is inclusive. |
