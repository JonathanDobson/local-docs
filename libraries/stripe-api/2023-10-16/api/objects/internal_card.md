# Stripe API 2023-10-16 — `internal_card` object

| Field | Type | Required | Description |
|---|---|---|---|
| `brand` | string |  | Brand of the card used in the transaction |
| `country` | string |  | Two-letter ISO code representing the country of the card |
| `exp_month` | integer |  | Two digit number representing the card's expiration month |
| `exp_year` | integer |  | Two digit number representing the card's expiration year |
| `last4` | string |  | The last 4 digits of the card |
