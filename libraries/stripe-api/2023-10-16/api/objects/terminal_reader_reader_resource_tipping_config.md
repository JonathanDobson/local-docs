# Stripe API 2023-10-16 — `terminal_reader_reader_resource_tipping_config` object

Represents a per-transaction tipping configuration

| Field | Type | Required | Description |
|---|---|---|---|
| `amount_eligible` | integer |  | Amount used to calculate tip suggestions on tipping selection screen for this transaction. Must be a positive integer in the smallest currency unit (e.g., 100 cents to represent $1.00 or 100 to represent ¥100, a zero-decimal currency). |
