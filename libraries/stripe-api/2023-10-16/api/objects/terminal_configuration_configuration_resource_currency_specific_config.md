# Stripe API 2023-10-16 — `terminal_configuration_configuration_resource_currency_specific_config` object

| Field | Type | Required | Description |
|---|---|---|---|
| `fixed_amounts` | array of integer |  | Fixed amounts displayed when collecting a tip |
| `percentages` | array of integer |  | Percentages displayed when collecting a tip |
| `smart_tip_threshold` | integer |  | Below this amount, fixed amounts will be displayed; above it, percentages will be displayed |
