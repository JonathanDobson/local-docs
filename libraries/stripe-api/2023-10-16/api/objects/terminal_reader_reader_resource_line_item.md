# Stripe API 2023-10-16 — `terminal_reader_reader_resource_line_item` object

Represents a line item to be displayed on the reader

| Field | Type | Required | Description |
|---|---|---|---|
| `amount` | integer | yes | The amount of the line item. A positive integer in the [smallest currency unit](https://stripe.com/docs/currencies#zero-decimal). |
| `description` | string | yes | Description of the line item. |
| `quantity` | integer | yes | The quantity of the line item. |
