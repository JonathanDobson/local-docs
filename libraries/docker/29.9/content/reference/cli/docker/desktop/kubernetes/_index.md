# docker desktop kubernetes

**Description:** Manage Kubernetes settings

**Usage:** `docker desktop kubernetes`
















## Subcommands

| Command | Description |
|---------|-------------|
| [`docker desktop kubernetes images`](https://docs.docker.com/reference/cli/docker/desktop/kubernetes/images/) | List Kubernetes images used by Docker Desktop |
| [`docker desktop kubernetes reset-cluster`](https://docs.docker.com/reference/cli/docker/desktop/kubernetes/reset-cluster/) | Reset the Kubernetes cluster managed by Docker Desktop |
| [`docker desktop kubernetes status`](https://docs.docker.com/reference/cli/docker/desktop/kubernetes/status/) | Get the status of the Kubernetes cluster managed by Docker Desktop |
