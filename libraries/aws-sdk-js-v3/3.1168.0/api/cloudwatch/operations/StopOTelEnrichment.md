# StopOTelEnrichment

Service: Amazon CloudWatch · SDK for JavaScript v3: `StopOTelEnrichmentCommand` from `@aws-sdk/client-cloudwatch`

Disables enrichment and PromQL access for CloudWatch vended metrics for [supported Amazon Web Services resources](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/UsingResourceTagsForTelemetry.html) in the account. After disabling,
these metrics are no longer enriched with resource ARN and resource tag labels, and
cannot be queried using PromQL.

## Input (`StopOTelEnrichmentInput`)

_None._

## Output (`StopOTelEnrichmentOutput`)

_None._
