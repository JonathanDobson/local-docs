# Help with ChromeDriver

If you have a general question or need help using ChromeDriver, you can email
the [chromedriver-users group](https://groups.google.com/g/chromedriver-users).

Before filing a bug, look at the
[existing issues](http://code.google.com/p/chromedriver/issues/)
for the same topic.

ChromeDriver is an open source project, worked on by various contributors
who monitor the issue list periodically. The issue is given a priority and
a status.

## Priority

- P0 - will resolve before next release
- P1 - consider resolving for next release
- P2 - consider resolving for next quarter
- P3 - low priority

## Status

Open statuses:

- Unconfirmed - New, has not been verified or reproduced
- Untriaged - Confirmed, not reviewed for priority and assignment
- Available - Triaged, but no owner assigned
- Assigned - In someone's queue, but not started
- Started - Work in progress
- ExternalDependency - Requires action from a third party

Closed statuses:

- Fixed - Work completed, needs verification
- Verified - Test or reporter verified that the fix works
- Duplicate - Same root cause as another issue
- WontFix - Cannot reproduce, works as intended, invalid, or obsolete
- Archived - Old issue with no activity

## Support policy

Only the current stable and beta versions of ChromeDriver are supported. Any
bugs filed against an older version of ChromeDriver may be closed.
